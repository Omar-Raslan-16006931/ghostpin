## Ghostpin

Download **Ghostpin.exe** below. It's one file with no install needed. On first run, Windows SmartScreen may warn about an unsigned app: click **More info → Run anyway**.

### What's inside
- Real map (dark, streets, satellite, hybrid) with search, coordinates and Google Maps links
- Teleport, plus saved places, history and presets (Riyadh, Saudi Arabia, Egypt, world)
- Drive mode: real-road routing, multiple stops, alternative routes, realistic acceleration and cornering, Once / Loop / Back & forth, scrubbing, live ETA
- Joystick (WASD / arrows, Shift = 2×)
- GPX import and export
- Classic engine (pymobiledevice3 CLI, most compatible) and Fast engine (live connection)

See the [README](https://github.com/Omar-Raslan-16006931/ghostpin#setup) for one-time setup (Apple Devices, Trust, Developer Mode).
