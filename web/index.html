First-time setup checklist
  1. Install Apple Devices (Microsoft Store) or iTunes so Windows can talk to the iPhone.
  2. Connect with a data cable, unlock the phone and tap Trust.
  3. On the iPhone: Settings › Privacy & Security › Developer Mode → On, then restart.
  4. Click Connect. The first time, Ghostpin downloads Apple's developer disk image (needs internet).
  5. If Classic fails, try Fast (smoother joystick). iOS 17.0 – 17.3 on Fast: click Start admin tunnel, approve, then Connect with "Use admin tunnel" on.
